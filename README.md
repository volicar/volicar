- **Full-stack:** Next.js Route Handlers and Server Components, Node.js, PostgreSQL and Supabase, multi-tenant apps with Row Level Security
- **AI engineering:** Anthropic Claude and OpenAI integrations, agents with state-machine guardrails and human handoff, AI-first workflow with Claude Code

### Featured work

**[iLABS: clinical laboratory website](https://www.ilabslaboratorio.com.br)** · Next.js · TypeScript · Supabase

Built end to end: the public site plus an admin area with a custom CMS, image uploads, Supabase Auth with Row Level Security, dynamic Open Graph images and technical SEO.

**WhatsApp AI sales agent** · Next.js · Supabase · Evolution API · Claude

Answers customers, looks up the product catalog and generates Pix payments. A state machine lets the model run the conversation while deterministic code owns prices and payments, with escalation to a human on edge cases.

**[cite-or-silence](https://github.com/volicar/cite-or-silence)** · Next.js · TypeScript · Supabase pgvector · Claude

A RAG assistant that answers with verifiable citations, or stays silent. Retrieval gates the model call, a citation check rejects unsupported answers, and an offline eval runs in CI as a regression gate.
